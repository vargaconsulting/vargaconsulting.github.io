# Presentations Portfolio

A curated set of talks on HDF5, C++, HPC, and performance engineering.  
Click a title to open the live Reveal.js deck.  

*⚠️ Some presentations are currently unavailable. See [note](#note).*


## 2021

- [**HDF Clinic 2021**][300] — practical HDF5 workflows, tips, and patterns for real projects. [:material-link:][300]
- [**C++ Meeting 2021 (Tool Fair)**][301] — toolchain and developer-experience deep dive for modern C++. [:material-link:][301] 
- [**C++ Tool Fair: String Performance**][302] — micro-benchmarks, allocation patterns, and fast string handling. [:material-link:][302]
- [**C++ Toronto 2021**][303] — modern C++ techniques from real trading/HPC workloads. [:material-link:][303]
- [**FNAL 2021 Online**][304] — data plumbing + analysis pipelines for large scientific datasets. [:material-link:][304]
- **HUG (Europe) 2021 — MPI** — parallel I/O, MPI + HDF5 integration, scalability trade-offs. :warning:
- [**HUG (Europe) 2021 — Benchmarks**][306] — storage/compute benchmarks, throughput/latency, and formats. [:material-link:][306]
- [**HUG (Europe) 2021 — H5CPP**][307] — compiler-assisted reflection + low-latency I/O in modern C++. [:material-link:][307]  

## 2020

- [**HDF Group Webinar 2020**][200] — fast ingestion, schema design, and analysis with HDF5. [:material-link:][200]
- [**HUG Online (USA) 2020**][201] — lessons from production pipelines; formats, compression, access patterns. [:material-link:][201]
- **C++ Toronto 2020** — performance-first C++ patterns; memory layout, I/O, and latency. :warning:

## 2018

- [**C++ Chicago 2018**][100] — early H5CPP concepts, type reflection, and persistent containers. [:material-link:][100]
